# synth-data-demo-terraform

Demo stack: a Python script runs on ECS Fargate and works with data in Redshift.

## What's deployed (per environment, default `dev`)

| Piece | Resource |
|---|---|
| VPC | 2 public subnets across 2 AZs (`network.tf`) |
| Redshift | Single-node `ra3.large` cluster, DB `synthdata` (`redshift.tf`) |
| Compute | ECS cluster + Fargate task definition, `python:3.12-slim` (`ecs.tf`) |
| Storage | S3 bucket `synth-data-demo-<env>-data` (`s3.tf`) |
| IAM | Task role (Redshift Data API + S3), execution role (SSM secret), local-user policy (`iam.tf`) |

The Redshift master password is generated by Terraform and stored as an SSM
SecureString: `/synth-data-demo/dev/redshift-master-password`. The Fargate task
receives it as the `DB_PASSWORD` env var at start; nothing is committed to git.

## Common commands

```sh
export AWS_PROFILE=synth-data-demo   # local profile with creds
export AWS_REGION=us-east-1

terraform init
terraform plan
terraform apply

# Redshift master password (when connecting from this PC)
aws ssm get-parameter \
  --name /synth-data-demo/dev/redshift-master-password \
  --with-decryption --query Parameter.Value --output text

# Launch the Fargate task (exact command is in the `run_task_command` output)
aws ecs run-task --cluster synth-data-demo-dev \
  --task-definition synth-data-demo-dev \
  --launch-type FARGATE \
  --network-configuration "awsvpcConfiguration={subnets=[<subnets>],securityGroups=[<fargate-sg>],assignPublicIp=ENABLED}"

# Task logs
aws logs tail /ecs/synth-data-demo-dev --follow

# Query Redshift from this PC (uses the attached IAM policy)
aws redshift-data execute-statement \
  --cluster-identifier synth-data-demo-dev --database synthdata \
  --db-user admin --sql "SELECT 1"

# Tear everything down (Redshift bills hourly while running)
terraform destroy
```

## Running a real script

Set `container_command` (in `variables.tf` or via `-var`/tfvars) to your script
 invocation, or point `container_image` at your own image. The container gets
 these env vars: `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`,
 `S3_BUCKET`, `AWS_REGION`.
